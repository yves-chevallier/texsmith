\section{Introduction}
TeXSmith renders emoji as glyphs when you pick a font flavour:
\begin{tscode}[lang=yaml, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{n+nt}{press}\PY{p}{:}
\PY{+w}{  }\PY{n+nt}{fonts}\PY{p}{:}
\PY{+w}{    }\PY{n+nt}{emoji}\PY{p}{:}\PY{+w}{ }\PY{l+lScalar+lScalarPlain}{black}
\end{Verbatim}
\end{tscode}
You can choose among four built-in options:
\begin{description}
\item[{\tscodeinline{black}}] OpenMoji Black (default).
\item[{\tscodeinline{color}}] Noto Color Emoji.
\item[{\tscodeinline{twemoji}}] Use the \tscodeinline{twemoji} package as fallback.
\item[{\tscodeinline{artifact}}] Download emoji as images using Twemoji.
\end{description}
Any other name is treated as a custom font family to load directly.

Engines:
\begin{itemize}
\item \tslogo{LuaLaTeX} relies on \tscodeinline{luaotfload} to add the emoji font as a fallback.
\item \tslogo{XeLaTeX}/Tectonic use \tscodeinline{ucharclasses} to automatically switch to the emoji font on the U+1F000--U+1FAFF range.
You can type emoji directly in Markdown or \LaTeX{} source.
\end{itemize}
