\textbf{TeXSmith} turns \href{https://www.markdownguide.org/}{Markdown} into
press-ready \href{https://www.latex-project.org/}{\LaTeX{}}. Keep your
docs authored in Markdown, then compile polished PDFs for print,
journals, or long-form review packages---without maintaining several sources of truth. No need to learn \LaTeX{}, install heavy toolchains, or wrestle with complex conversion setups.

\section{Why would I use TeXSmith?}
TeXSmith bridges the gap between lightweight Markdown authoring
and the typographic power of \LaTeX{}. It is ideal for:
\begin{itemize}
\item Writing scientific articles.
\item Writing product documentation.
\item Writing books.
\item Writing letters.
\item Writing technical reports.
\item Writing cooking recipes and more.
\end{itemize}
The combination with MkDocs provides a single source of truth for both web and PDF output, which improves collaboration because all documentation lives in Markdown in a Git repository. Versioning with MkDocs stays simple and natural.

\section{The dialect}
TeXSmith reads TMark: \href{https://commonmark.org/}{CommonMark},
plus the extension set every MkDocs site already loads, plus exactly four
syntactic families for what print needs --- attributes, roles, container
directives and data directives --- and two sigils: \textbf{\tscodeinline{\#} defines, \tscodeinline{@} refers}.

\section{How is it different from Pandoc?}
\href{https://pandoc.org/}{Pandoc} is a powerhouse, but reproducing an extended
Markdown dialect in Pandoc requires custom filters and ongoing maintenance.
TeXSmith delivers parity with the MkDocs world out of the box:
\begin{itemize}
\item Handles Material-only components such as tabbed content, callouts, and
keyboard keys.
\item Ships with diagram converters (Mermaid, Draw.io) that plug directly
into the \LaTeX{} build step.
\item Exposes the same primitives via the CLI and Python API, so automation scripts
match what authors do locally.
\item Every construct says how it degrades elsewhere, and Pandoc's own citation
grammar is accepted for import.
\end{itemize}
Use both tools together when it makes sense; reach for TeXSmith when MkDocs \tsscript{symbols}{\(\rightarrow\) }\LaTeX{}
compatibility is the priority.
