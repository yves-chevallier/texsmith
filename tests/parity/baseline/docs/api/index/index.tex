\section{API Sections}
\begin{description}
\item[{\tscodeinline{high-\allowbreak{}level}}] High-level orchestration helpers (\tscodeinline{ConversionService}, \tscodeinline{TemplateSession}) for programmatic conversions and template sessions.
\item[{\tscodeinline{core}}] Core package modules (\tscodeinline{texsmith}, configuration, contexts, conversion helpers, etc.).
\item[{\tscodeinline{bibliography}}] Bibliography tooling (\tslogo{BibTeX} parsing, DOI resolution, issue reporting).
\item[{\tscodeinline{cli}}] Command-line entry points and utilities.
\item[{\tscodeinline{handlers}}] IR passes and fragment contracts --- the two extension points of the \tscodeinline{parse \(\rightarrow\) IR \(\rightarrow\) passes \(\rightarrow\) resolve \(\rightarrow\) write} pipeline.
\item[{\tscodeinline{latex}}] \LaTeX{} infrastructure (formatter, renderer, templates).
\item[{\tscodeinline{markdown}}] Markdown conversion helpers and custom extensions.
\item[{\tscodeinline{plugins}}] Optional integrations (MkDocs Material-specific handlers).
\item[{\tscodeinline{transformers}}] Asset conversion strategies (SVG, Draw.io, Mermaid, remote images).
\end{description}
