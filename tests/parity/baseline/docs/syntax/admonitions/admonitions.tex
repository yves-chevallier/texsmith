Admonitions are little callout blocks for surfacing notes, warnings, tips, and whatever else you need to highlight. Python-Markdown's \texttt{admonition} extension powers them.

You can render them in two flavors. The plain/static variant looks like this:

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
!!! note \PYZdq{}This is a Note\PYZdq{}
    Any number of other indented Markdown elements.

    This is the second paragraph.
\end{Verbatim}
\end{code}
\begin{callout}[callout note]{This is a Note}
Any number of other indented Markdown elements.

This is the second paragraph.
\end{callout}
Prefer collapsible callouts? Use the foldable form:

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
??? note \PYZdq{}This is a Note\PYZdq{}
    Any number of other indented markdown elements.

    This is the second paragraph.
\end{Verbatim}
\end{code}
\begin{callout}[callout note]{This is a Note}
Any number of other indented markdown elements.

This is the second paragraph.
\end{callout}
\section{LaTeX Rendering}\label{latex-rendering}

TeXSmith maps admonitions onto the \texttt{tcolorbox} package automatically, so they come through in \LaTeX{} without extra work. Template authors can still restyle them via the preamble or dedicated slots.

Built-in templates like \texttt{article} and \texttt{book} ship with sensible defaults. Tweak the look by setting \texttt{callout\_style} in front matter (or via \texttt{-\allowbreak{}-\allowbreak{}attribute callout\_style=<style>}):

\begin{code}{yaml}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{n+nn}{\PYZhy{}\PYZhy{}\PYZhy{}}
\PY{n+nt}{press}\PY{p}{:}
\PY{+w}{  }\PY{n+nt}{callout\PYZus{}style}\PY{p}{:}\PY{+w}{ }\PY{l+lScalar+lScalarPlain}{classic}\PY{+w}{  }\PY{c+c1}{\PYZsh{} fancy | classic | minimal}
\PY{n+nn}{\PYZhy{}\PYZhy{}\PYZhy{}}
\end{Verbatim}
\end{code}
\begin{itemize}
\item{} \texttt{fancy} (default): colored headings with icons.
\item{} \texttt{classic}: black-and-white layout with a bold left rule.
\item{} \texttt{minimal}: subtle border, rounded corners, and no icons.

\end{itemize}
