MkDocs and Python-Markdown support the \texttt{[[Wiki Link]]} syntax via the \texttt{wikilinks}
extension. TeXSmith keeps that behavior so you can link between pages without
remembering exact file paths.

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
[[Getting Started]]
[[Subfolder/Page Title|Custom label]]
\end{Verbatim}
\end{code}
\begin{itemize}
\item{} The portion before the pipe resolves to a Markdown file (\texttt{Getting Started} \(\rightarrow\)
  \texttt{getting-\allowbreak{}started.md}).
\item{} Anything after \texttt{|} becomes the rendered link text.
\item{} When building PDFs, TeXSmith turns wiki links into standard hyperlinks, so the
  references remain navigable.

\end{itemize}
