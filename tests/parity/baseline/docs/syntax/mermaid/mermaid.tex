Just like MkDocs, TeXSmith understands \href{https://mermaid.js.org}{Mermaid} diagrams. Browsers render them on the fly, but PDFs need static assets, so TeXSmith converts each diagram into a vector PDF during the build. That requires either:

\begin{enumerate}
\item Installing \texttt{mermaid-\allowbreak{}cli} and its dependencies in your environment, or
\item Using Docker with the pulled image \texttt{mermaidjs/mermaid-\allowbreak{}cli}.

\end{enumerate}

\section{External diagrams}\label{external-diagrams}

Sometimes diagrams live better outside the Markdown. TeXSmith supports:

\begin{enumerate}
\item Reference external \texttt{.mmd} / \texttt{.mermaid} files.
\item Embed Mermaid Live snippets using \texttt{pako:} URLs for live editing.

\end{enumerate}
The \texttt{texsmith.extensions.mermaid} extension sniffs out these references, pulls the content in, and treats inline/external sources the same way.

Using a \texttt{mmd} file is as simple as including an image:

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
![\PY{n+nt}{Build pipeline}](\PY{n+na}{../assets/mermaid.mmd})
\end{Verbatim}
\end{code}

\section{Conversion by TeXSmith}\label{conversion-by-texsmith}

All Mermaid diagrams are converted to PDF and included with \texttt{\textbackslash{}includegraphics}
so they integrate cleanly with templates and \LaTeX{} floats.

Printed output might deserve a different theme. Point \texttt{mermaid\_config} to a JSON config (front matter or CLI \texttt{-\allowbreak{}-\allowbreak{}attribute press.mermaid\_config=...}) to override:

\begin{code}{yaml}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{n+nn}{\PYZhy{}\PYZhy{}\PYZhy{}}
\PY{n+nt}{press}\PY{p}{:}
\PY{+w}{  }\PY{n+nt}{mermaid\PYZus{}config}\PY{p}{:}\PY{+w}{ }\PY{l+lScalar+lScalarPlain}{mermaid\PYZhy{}config.json}
\PY{n+nn}{\PYZhy{}\PYZhy{}\PYZhy{}}
\end{Verbatim}
\end{code}
Alternatively, you can add a \texttt{mermaid-\allowbreak{}config.json} file to the \texttt{\textasciitilde{}/.texsmith/} directory
to apply it globally to all your TeXSmith projects.
