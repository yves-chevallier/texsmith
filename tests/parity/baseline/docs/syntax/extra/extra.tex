\section{Attribute Lists}\label{attribute-lists}

Attribute Lists add lightweight metadata to headings, paragraphs, images, links, and more. Drop a brace block right after the element:

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{g+gh}{\PYZsh{} Header 1 \PYZob{}\PYZsh{}header1 .class1 key=\PYZdq{}value\PYZdq{}\PYZcb{}}

This is a paragraph with a class and an ID.
\PYZob{}: \PY{n+ni}{\PYZsh{}para1} .text key=\PYZdq{}value\PYZdq{} \PYZcb{}

![\PY{n+nt}{Alt text}](\PY{n+na}{image.jpg})\PYZob{}\PYZsh{}img1 .responsive width=\PYZdq{}300\PYZdq{}\PYZcb{}

| set on td    | set on em   |
|\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}|\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}\PYZhy{}|
