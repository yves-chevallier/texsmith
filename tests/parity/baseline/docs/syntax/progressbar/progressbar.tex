\title{Progress Bars}
\author{}\date{}
\begin{document}
\maketitle
A progress bar is an inline node with a value and an optional label. The
spelling is PyMdownX's and is the canonical one, so the HTML preview and the
PDF build stay in sync out of the box; in print it becomes a \tscodeinline{\textbackslash{}tsprogress}
call from the \tscodeinline{ts-\allowbreak{}typesetting} fragment, over the
\href{https://ctan.org/pkg/progressbar}{\tscodeinline{progressbar}} package.
\section{Syntax}
\begin{tscode}[lang=markdown, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
[=25\PYZpc{} \PYZdq{}Research\PYZdq{}]
[=50\PYZpc{} \PYZdq{}Implementation\PYZdq{}]
[=75\PYZpc{} \PYZdq{}Review\PYZdq{}]
[=100\PYZpc{} \PYZdq{}Launch\PYZdq{}]\PYZob{}.thin\PYZcb{}
\end{Verbatim}
\end{tscode}
\begin{itemize}
\item Values must be percentages (\tscodeinline{0 – 100}). TeXSmith clamps the values if needed.
\item The quoted label is optional; when omitted the percentage is used.
\item A trailing attribute list (\tscodeinline{\{.class \#id\}}) attaches on any host. Use the
\tscodeinline{.thin} class to halve the bar height (e.g. for tables or dense summaries);
other classes reach the web stylesheet and are ignored in print.
\item The bar is \textbf{inline}, so it fits in a table cell. Consecutive bars on
separate lines are separate paragraphs or hard-broken lines, and the template
chooses the width.
\item The fraction form \tscodeinline{[=9/20 "Review"]} and the \tscodeinline{\{: .thin\}} attribute spelling
are deprecated sugar, normalised by \tscodeinline{tmark lint -\allowbreak{}-\allowbreak{}fix}; see
Migrating to TMark.
\end{itemize}
\section{\LaTeX{} output}
The writer emits \tscodeinline{\textbackslash{}tsprogress[thin]\{0.45\}\{label\}}; the fragment expands it to a
\tscodeinline{\textbackslash{}progressbar} call with the following defaults:
\begin{tscode}[lang=latex, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{n+nb}{\PYZob{}}\PY{k}{\PYZbs{}progressbar}[
  width=9cm,
  heighta=12pt,
  roundnessr=0.1,
  borderwidth=1pt,
  linecolor=black,
  filledcolor=black!60,
  emptycolor=black!10
]\PY{n+nb}{\PYZob{}}0.73\PY{n+nb}{\PYZcb{}} Launch\PY{n+nb}{\PYZcb{}}
\end{Verbatim}
\end{tscode}
The \tscodeinline{.thin} class switches \tscodeinline{heighta} to \tscodeinline{6pt}. For more control, redefine
\tscodeinline{\textbackslash{}tsprogress} in your template or append to its \tscodeinline{pgfkeys} family.
