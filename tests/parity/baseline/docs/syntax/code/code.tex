Code fences are one of Markdown's greatest hits: drop a triple backtick block, label it, and you get nicely formatted snippets. TeXSmith leans on the \texttt{minted} package for \LaTeX{} output. It's a bit slower than \texttt{listings}, but the highlighting is richer, it speaks more languages, and its Unicode support (especially under Xe\LaTeX{}/Lua\LaTeX{}) is top-notch.

\section{Code Blocks}\label{code-blocks}

You can insert code snippets and specify options for syntax highlighting.

\begin{itemize}
\item{} Line numbers with \texttt{linenums="1"}
\item{} Title with \texttt{title="filename.ext"}
\item{} Highlight specific lines with \texttt{hl\_lines="2-\allowbreak{}3"}

\end{itemize}

\subsection{Snippets}\label{snippets}

With \texttt{pymdownx.snippets} you can pull code from external files, keeping samples reusable across docs.

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{l+s+sb}{```}\PY{l+s+sb}{python}
\PY{o}{\PYZhy{}}\PY{o}{\PYZhy{}}\PY{l+m+mi}{8}\PY{o}{\PYZlt{}}\PY{o}{\PYZhy{}}\PY{o}{\PYZhy{}} \PY{l+s+s2}{\PYZdq{}}\PY{l+s+s2}{examples/code/bubble\PYZus{}sort.py}\PY{l+s+s2}{\PYZdq{}}
\PY{l+s+sb}{```}
\end{Verbatim}
\end{code}
\begin{callout}[callout tip]{Tip}
If you're using MkDocs, ensure that the \texttt{base\_path} for snippets is correctly set in your configuration to point to the directory containing your code files.

A safe configuration would be:

\begin{code}{yaml}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
\PY{p+pIndicator}{\PYZhy{}}\PY{+w}{ }\PY{n+nt}{pymdownx.snippets}\PY{p}{:}
\PY{+w}{    }\PY{n+nt}{check\PYZus{}paths}\PY{p}{:}\PY{+w}{ }\PY{l+lScalar+lScalarPlain}{true}
\PY{+w}{    }\PY{n+nt}{base\PYZus{}path}\PY{p}{:}\PY{+w}{ }\PY{k+kt}{!relative}\PY{+w}{ }\PY{l+lScalar+lScalarPlain}{\PYZdl{}config\PYZus{}dir}
\end{Verbatim}
\end{code}
\end{callout}

\section{Inline Code}\label{inline-code}

You can also include inline code snippets using backticks \texttt{`} like this:

\subsection{Unformatted}\label{unformatted}

\begin{code}{markdown}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
To sort a list in Python, you can use the \PY{l+s+sb}{`sorted()`} function.
\end{Verbatim}
