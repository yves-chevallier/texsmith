\section{TeXSmith releases}\label{texsmith-releases}

\begin{center}
\begin{tabularx}{\linewidth}{>{\raggedright\arraybackslash}X>{\raggedright\arraybackslash}X>{\raggedright\arraybackslash}X}
\toprule
\textbf{Version} & \textbf{Highlights} & \textbf{Notes} \\

\midrule
\texttt{0.1.0} & Unified conversion engine (\texttt{ConversionService}, slot assignments, diagnostics emitters), Typer CLI with \texttt{render}/\texttt{bibliography}, initial template catalog (article, book), diagram adapters (Mermaid, Draw.io, Svgbob), MkDocs integration hooks. & Requires Python 3.10+, MkDocs \(\geq\) 1.6 for docs. Templates target TeX Live 2023. \\
\texttt{0.4.0} & Fragment manifest/ABC (attributes, partials, slot validation), explicit partial precedence (template > fragment > core), template discovery order (built-ins \(\rightarrow\) packages \(\rightarrow\) local \(\rightarrow\) \texttt{\textasciitilde{}/.texsmith/templates}), improved \texttt{-\allowbreak{}-\allowbreak{}template-\allowbreak{}info} output (slots, fragments, attribute columns). & Update custom fragments to \texttt{fragment.toml} + \texttt{partials}/\texttt{required\_partials}; remove legacy template attributes (cover/twocolumn/backmatter/emoji) and use fragment-provided options instead. Use \texttt{texsmith templates} to confirm discovery. \\

\bottomrule
\end{tabularx}
\end{center}

Future releases will append to this table with new features, migration notes, and API changes. If you upgrade past the compatibility range declared in a template manifest (\texttt{[compat]}), update the template and rerun its smoke tests.

To inspect third-party or local templates, run:

\begin{code}{bash}{}{}
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
texsmith\PY{+w}{ }\PYZhy{}\PYZhy{}template\PY{+w}{ }\PYZlt{}name\PYZhy{}or\PYZhy{}path\PYZgt{}\PY{+w}{ }\PYZhy{}\PYZhy{}template\PYZhy{}info
\end{Verbatim}
\end{code}
The command lists TeX Live requirements, shell-escape expectations, slot definitions, and declared assets.

\section{Upgrade checklist}\label{upgrade-checklist}

\begin{enumerate}
\item Run \texttt{uv run mkdocs build} to confirm docs compile without warnings on the new release.
\item Update your TeX Live image with any new packages referenced in the table above or in \texttt{template-\allowbreak{}info}.
\item Rebuild the examples (\texttt{docs/examples/index.md}) and confirm smoke tests still pass.
\item Capture notable migrations (CLI flags, metadata schema changes) in this page and link PRs or release notes for future reference.

\end{enumerate}
