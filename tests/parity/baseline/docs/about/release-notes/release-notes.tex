Use this page to see what changed in each TeXSmith release and which \LaTeX{} prerequisites (\TeX{} Live year, \tscodeinline{tlmgr} packages, shell-escape requirements) the bundled templates expect. Update your automation and CI images accordingly before bumping versions.
\section{TeXSmith releases}
\begin{center}
\begin{tabularx}{\linewidth}{>{\raggedright\arraybackslash}X>{\raggedright\arraybackslash}X>{\raggedright\arraybackslash}X}
\toprule
\textbf{Version} & \textbf{Highlights} & \textbf{Notes} \\
\midrule
\tscodeinline{0.1.0} & Unified conversion engine (\tscodeinline{ConversionService}, slot assignments, diagnostics emitters), Typer CLI with \tscodeinline{render}/\tscodeinline{bibliography}, initial template catalog (article, book), diagram adapters (Mermaid, Draw.io, Svgbob), MkDocs integration hooks. & Requires Python 3.10+, MkDocs \tsscript{mathematics}{\(\geq\) }1.6 for docs. Templates target \TeX{} Live 2023. \\
\tscodeinline{0.4.0} & Fragment manifest/ABC (attributes, partials, slot validation), explicit partial precedence (template > fragment > core), template discovery order (built-ins \tsscript{symbols}{\(\rightarrow\) }packages \tsscript{symbols}{\(\rightarrow\) }local \tsscript{symbols}{\(\rightarrow\) }\tscodeinline{\textasciitilde{}/.texsmith/templates}), improved \tscodeinline{-\allowbreak{}-\allowbreak{}template-\allowbreak{}info} output (slots, fragments, attribute columns). & Update custom fragments to \tscodeinline{fragment.toml} + \tscodeinline{partials}/\tscodeinline{required\_partials}; remove legacy template attributes (cover/twocolumn/backmatter/emoji) and use fragment-provided options instead. Use \tscodeinline{texsmith templates} to confirm discovery. \\
\bottomrule
\end{tabularx}
\end{center}
Future releases will append to this table with new features, migration notes, and API changes. If you upgrade past the compatibility range declared in a template manifest (\tscodeinline{[compat]}), update the template and rerun its smoke tests.

To inspect third-party or local templates, run:
\begin{tscode}[lang=bash, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
texsmith\PY{+w}{ }\PYZhy{}\PYZhy{}template\PY{+w}{ }\PYZlt{}name\PYZhy{}or\PYZhy{}path\PYZgt{}\PY{+w}{ }\PYZhy{}\PYZhy{}template\PYZhy{}info
\end{Verbatim}
\end{tscode}
The command lists \TeX{} Live requirements, shell-escape expectations, slot definitions, and declared assets.
\section{Upgrade checklist}
\begin{enumerate}
\item Run \tscodeinline{uv run mkdocs build} to confirm docs compile without warnings on the new release.
\item Update your \TeX{} Live image with any new packages referenced in the table above or in \tscodeinline{template-\allowbreak{}info}.
\item Rebuild the examples (\tscodeinline{docs/examples/index.md}) and confirm smoke tests still pass.
\item Capture notable migrations (CLI flags, metadata schema changes) in this page and link PRs or release notes for future reference.
\end{enumerate}
