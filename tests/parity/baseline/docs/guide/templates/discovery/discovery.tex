\title{Template Discovery}
\author{}\date{}

\maketitle
TeXSmith finds templates from multiple locations in a deterministic order:
\begin{enumerate}
\item \textbf{Built-ins}: shipped with TeXSmith (\tscodeinline{article}, \tscodeinline{book}, \tscodeinline{letter}, \tscodeinline{snippet}).
\item \textbf{Installed packages}: PyPI distributions named \tscodeinline{texsmith-\allowbreak{}template-\allowbreak{}*} (or exposing the \tscodeinline{texsmith.templates} entry point).
\item \textbf{Local tree}: current working directory and any ancestor \tscodeinline{templates/} folder. Any \tscodeinline{manifest.toml}/\tscodeinline{template/manifest.toml} or \tscodeinline{\_\_init\_\_.py} counts as a template root.
\item \textbf{User directory}: \tscodeinline{\textasciitilde{}/.texsmith/templates/<name>} (same structure as local).
\end{enumerate}
Use the CLI to inspect what was found:
\begin{tscode}[lang=bash, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
texsmith\PY{+w}{ }\PYZhy{}\PYZhy{}list\PYZhy{}templates\PY{+w}{                    }\PY{c+c1}{\PYZsh{} every visible template, with its origin}
texsmith\PY{+w}{ }\PYZhy{}\PYZhy{}template\PY{+w}{ }article\PY{+w}{ }\PYZhy{}\PYZhy{}template\PYZhy{}info\PY{+w}{  }\PY{c+c1}{\PYZsh{} one template\PYZsq{}s slots and attributes}
\end{Verbatim}
\end{tscode}
A valid template root contains either \tscodeinline{manifest.toml} or \tscodeinline{template/manifest.toml}; an \tscodeinline{\_\_init\_\_.py} alongside these allows specialized Python logic.

Notes:
\begin{itemize}
\item Passing an explicit path (\tscodeinline{-\allowbreak{}-\allowbreak{}template ./templates/custom}) bypasses discovery order.
\item Package roots win over same-named local folders; local folders win over the home directory.
\item Template manifests can include a \tscodeinline{mermaid-\allowbreak{}config.json} at the root; \tscodeinline{-\allowbreak{}-\allowbreak{}template-\allowbreak{}info} will surface it.
\end{itemize}
To scaffold a built-in for customization:
\begin{tscode}[lang=bash, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
texsmith\PY{+w}{ }\PYZhy{}\PYZhy{}template\PY{+w}{ }article\PY{+w}{ }\PYZhy{}\PYZhy{}template\PYZhy{}scaffold\PY{+w}{ }./templates/article
\end{Verbatim}
\end{tscode}
Then point \tscodeinline{-\allowbreak{}-\allowbreak{}template} to that path. Any \tscodeinline{mermaid-\allowbreak{}config.json} placed at the template root will be picked up automatically.
