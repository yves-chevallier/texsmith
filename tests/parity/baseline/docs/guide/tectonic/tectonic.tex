\title{Tectonic Engine}

\maketitle
Tectonic is the default PDF engine in TeXSmith. It bundles automatic package
fetching, fast incremental builds, and minimal setup -- ideal for CI pipelines and
lightweight containers. You can switch to \tscodeinline{latexmk} with \tscodeinline{-\allowbreak{}-\allowbreak{}engine lualatex} or
\tscodeinline{-\allowbreak{}-\allowbreak{}engine xelatex} when you need full control of the traditional toolchain.
\section{Install Tectonic}
\begin{itemize}
\item \textbf{macOS:} \tscodeinline{brew install tectonic}
\item \textbf{Ubuntu/Debian:} \tscodeinline{sudo apt install tectonic} (or \tscodeinline{cargo install tectonic})
\item \textbf{Fedora:} \tscodeinline{sudo dnf install tectonic}
\item \textbf{Windows:} \tscodeinline{scoop install tectonic} or \tscodeinline{choco install tectonic}
\item \textbf{Fallback:} grab a prebuilt archive from \url{https://tectonic-typesetting.github.io/} and put
the \tscodeinline{tectonic} binary on your \tscodeinline{PATH}.
\end{itemize}
After installation, run \tscodeinline{tectonic -\allowbreak{}-\allowbreak{}version} to confirm the binary is available.
\section{Building with Tectonic}
\begin{itemize}
\item CLI: \tscodeinline{texsmith notes.md -\allowbreak{}-\allowbreak{}template article -\allowbreak{}-\allowbreak{}build} uses Tectonic automatically.
\item Latexmk: add \tscodeinline{-\allowbreak{}-\allowbreak{}engine lualatex} (or \tscodeinline{-\allowbreak{}-\allowbreak{}engine xelatex}) to opt into the latexmk +
\tscodeinline{.latexmkrc} flow.
\item API: call \tscodeinline{ConversionService.build\_pdf(render\_result, engine="tectonic")} after
rendering a template.
\end{itemize}
TeXSmith still checks for optional helpers -- \tscodeinline{biber}, \tscodeinline{makeindex}/\tscodeinline{texindy},
\tscodeinline{makeglossaries} -- and reports anything missing before the engine runs.
