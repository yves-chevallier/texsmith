\thispagestyle{plain}
Fragments are reusable \LaTeX{} snippets injected into template slots. Built-in fragments (e.g., geometry, fonts, glossary, index) and custom ones share the same structure:

\begin{itemize}
\item{} \texttt{fragment.toml} with \texttt{name}, \texttt{description}, and either an \texttt{entrypoint} or a \texttt{files} list.
\item{} Optional \texttt{attributes} section describing fragment-owned attributes (ownership enforced).
\item{} Optional \texttt{partials} block for fragment-scoped partial overrides and \texttt{required\_partials} for dependencies.
\item{} Optional \texttt{should\_render} logic (via entrypoint) to render only when needed.

\end{itemize}

\section{Fragment pieces}\label{fragment-pieces}

\begin{itemize}
\item{} \texttt{package}: rendered to a \texttt{.sty} file and injected via \texttt{\textbackslash{}usepackage} into the target slot.
\item{} \texttt{input}: rendered to \texttt{.tex} and injected via \texttt{\textbackslash{}input\{\}} into the target slot.
\item{} \texttt{inline}: rendered string injected directly into the slot variable (no file emitted).

\end{itemize}
Slots are validated against the template at render time; inline injections must match declared slots or template variables.

\section{Attributes}\label{attributes}

Fragments can declare attributes (ownership enforced) and resolve overrides using the same \texttt{TemplateAttributeSpec} model as templates. Attribute defaults are injected into the context before rendering fragment pieces. Attribute ownership matters: if two fragments (or a template) claim the same attribute name, TeXSmith raises a \texttt{TemplateError}. Keep each attribute owned by a single fragment or the template to avoid conflicts.

\section{Partials}\label{partials}

\section{Runtime loading}\label{runtime-loading}

\begin{itemize}
\item{} Built-ins are discovered under \texttt{src/texsmith/fragments/**/fragment.toml}.
\item{} Custom fragments can be passed via \texttt{press.fragments} in front matter or CLI attributes.
\item{} The registry uses manifest metadata first; entrypoint is a fallback.
\item{} \textbf{Entrypoint contract (Python)}: Must expose a module attribute \texttt{fragment} that is a \texttt{BaseFragment} instance. Legacy \texttt{create\_fragment()} factories are no longer used.

\end{itemize}
\section{Fragment contract (Python)}\label{fragment-contract-python}

\begin{itemize}
\item{} Implement a \texttt{BaseFragment[Config]} subclass with:
\item{} class attributes: \texttt{name}, \texttt{description}, \texttt{pieces}, \texttt{attributes} (TemplateAttributeSpec map), optional \texttt{context\_defaults}, \texttt{partials}, \texttt{required\_partials}, \texttt{source}.
\item{} methods: \texttt{build\_config(context, overrides=None) -\allowbreak{}> Config}, \texttt{inject(config, context, overrides=None) -\allowbreak{}> None}, \texttt{should\_render(config) -\allowbreak{}> bool}.
\item{} Define a \texttt{Config} dataclass with \texttt{from\_context(...)} and \texttt{inject\_into(context)} methods (plus helpers like \texttt{enabled()}).
\item{} Export \texttt{fragment = YourFragment()} from \texttt{\_\_init\_\_.py}; point \texttt{fragment.toml} \texttt{entrypoint} to \texttt{texsmith.fragments.yourname:fragment}.
\item{} Injection flow: registry merges attribute defaults, builds config, calls \texttt{inject}, then checks \texttt{should\_render} before rendering pieces.

\end{itemize}
\subsection{Minimal example}\label{minimal-example}

\texttt{src/texsmith/fragments/example/\_\_init\_\_.py}
\texttt{from dataclasses import dataclass
from pathlib import Path
from typing import Any, Mapping

from texsmith.core.fragments.base import BaseFragment, FragmentPiece
from texsmith.core.templates.manifest import TemplateAttributeSpec

@dataclass(frozen=True)
class ExampleConfig:
    message: str | None

    @classmethod
    def from\_context(cls, ctx: Mapping[str, Any]) -\allowbreak{}> "ExampleConfig":
        return cls(message=ctx.get("example\_message"))

    def inject\_into(self, ctx: dict[str, Any]) -\allowbreak{}> None:
        ctx["ts\_example\_message"] = self.message or "Hello"

    def enabled(self) -\allowbreak{}> bool:
        return bool(self.message)

class ExampleFragment(BaseFragment[ExampleConfig]):
    name = "ts-\allowbreak{}example"
    description = "Tiny example fragment."
    pieces = [
        FragmentPiece(
            template\_path=Path(\_\_file\_\_).with\_name("ts-\allowbreak{}example.jinja.tex"),
            kind="inline",
            slot="extra\_packages",
        )
    ]
    attributes = \{
        "example\_message": TemplateAttributeSpec(
            default=None,
            type="string",
            sources=["press.example.message", "example.message"],
        )
    \}
    context\_defaults: dict[str, Any] = \{"extra\_packages": ""\}
    config\_cls = ExampleConfig
    source = Path(\_\_file\_\_).with\_name("ts-\allowbreak{}example.jinja.tex")

    def build\_config(self, context: Mapping[str, Any], overrides=None) -\allowbreak{}> ExampleConfig:
        return self.config\_cls.from\_context(context)

    def inject(self, config: ExampleConfig, context: dict[str, Any], overrides=None) -\allowbreak{}> None:
        config.inject\_into(context)

    def should\_render(self, config: ExampleConfig) -\allowbreak{}> bool:
        return config.enabled()

fragment = ExampleFragment()
}

\texttt{src/texsmith/fragments/example/fragment.toml}

[[files]]

}

\section{Migration notes for fragment authors}\label{migration-notes-for-fragment-authors}

\begin{itemize}
\item{} Prefer \texttt{fragment.toml} with \texttt{files}, \texttt{attributes}, and optional \texttt{partials}/\texttt{required\_partials}; use an entrypoint only when you need Python logic.
\item{} If using Python, return a \texttt{BaseFragment} instance via \texttt{fragment}; \texttt{create\_fragment()} and \texttt{FragmentDefinition} shims have been removed.
\item{} Declare attribute ownership (implicit \texttt{owner = <fragment name>}) to avoid collisions with templates or other fragments.
\item{} Keep slot targets aligned with template variables; inline targets must reference declared slots or template variables, otherwise a \texttt{TemplateError} is raised.

\end{itemize}
