\section{Draw.io backend choice}\label{draw-io-backend-choice}

TeXSmith now tries a Playwright-based exporter first (cached under \texttt{\textasciitilde{}/.cache/texsmith/playwright}), falling back to the local \texttt{drawio}/\texttt{mmdc} CLI and finally the Docker image. Force a specific path with \texttt{-\allowbreak{}-\allowbreak{}diagrams-\allowbreak{}backend=playwright|local|docker} if needed.
