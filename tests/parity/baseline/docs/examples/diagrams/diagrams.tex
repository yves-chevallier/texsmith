Markdown doesn't have to be flat text. Here's how we wire live \href{https://mermaid.js.org/}{Mermaid} and \href{https://app.diagrams.net/}{Draw.io} diagrams straight into TeXSmith, no opaque binaries, friendly diffs.

\end{figure}

\begin{tscode}[lang=markdown, engine=pygments]
\begin{Verbatim}[commandchars=\\\{\},breaklines, breakanywhere, commandchars=\\\{\}]
[include: examples/diagrams/diagrams.md not found]
\end{Verbatim}
\end{tscode}

\section{Draw.io backend choice}
TeXSmith now tries a Playwright-based exporter first (cached under \tscodeinline{\textasciitilde{}/.cache/texsmith/playwright}), falling back to the local \tscodeinline{drawio}/\tscodeinline{mmdc} CLI and finally the Docker image. Force a specific path with \tscodeinline{-\allowbreak{}-\allowbreak{}diagrams-\allowbreak{}backend=playwright|local|docker} if needed.
