\section{Rendered Markdown}
Obviously everything built with TeXSmith can also be rendered in this very Markdown file:

\section{Draw.io backend choice}
TeXSmith now tries a Playwright-based exporter first (cached under \tscodeinline{\textasciitilde{}/.cache/texsmith/playwright}), falling back to the local \tscodeinline{drawio}/\tscodeinline{mmdc} CLI and finally the Docker image. Force a specific path with \tscodeinline{-\allowbreak{}-\allowbreak{}diagrams-\allowbreak{}backend=playwright|local|docker} if needed.
